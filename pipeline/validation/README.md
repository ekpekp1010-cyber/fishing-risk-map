# 게이트 2 검증: 과거 사고 재계산

PRD 성공 지표 "과거 사고 사례의 80% 이상이 '주의' 또는 '위험'으로 재현"을 확인한다.

```bash
cd pipeline && python -m fishrisk.incidents     # 사고 지점의 V (out/incidents/terrain.json)
cd .. && node pipeline/validation/gate2.mjs     # 과거 자료로 R 재계산 → gate2_results.md
```

| 파일 | 내용 |
| --- | --- |
| `incidents.csv` | 링컨 카운티 해안 사고 목록. 날짜·시각·좌표의 확실성과 출처(보도) |
| `gate2.mjs` | 과거 날씨(ERA5)·파랑(Open-Meteo Marine / ERA5 해양)·조위(NOAA 9435380 실측)·경보(IEM VTEC)로 `lib/risk` 계산 |
| `gate2_results.md` | 마지막 실행 결과 |

## 사고 목록 기준

- 해안에서 파도에 휩쓸린 사망·실종 사고만 넣었다. 선박 사고(야퀴나만 입구 전복 등)는 MVP 범위(갯바위·방파제·해변·하구 낚시)가 아니라 뺐다.
- 날짜를 확인하지 못한 사고(2008년 사우스 제티, 2025년 3월 링컨시티 통나무 사고)는 뺐다.
- 시각이 보도되지 않은 사고는 낮 시간대 창을 보고, 판정은 창의 가운데 시각으로 한다(`time_certainty`).
- 좌표는 보도된 장소 이름으로 잡은 근사값이다(`coord_certainty=approx`).

## 한계

- 사고 6건 중 시범 지역(뉴포트) 안은 1건이다. 나머지는 같은 링컨 카운티의 디포베이·오터 크레스트·실레츠만·야하츠로, 같은 방법으로 그 지점의 V를 새로 계산했다.
- 2022년 이전 파랑은 ERA5 해양 0.5° 격자라 운영 예보(Open-Meteo Marine)보다 거칠고, 너울 변수가 없어 유의파고·파랑 최대 주기로 대신한다.
- 조위는 뉴포트 관측소 하나의 값을 모든 지점에 쓴다(디포베이 약 20 km 북쪽).
- 표본이 작다(6건). 등급이 모두 위험으로 나와도 '사고가 없던 날'과 구별되는지는 따로 봐야 한다(대조군).

## 결과 해석 (2026-11-24)

### 1차: PRD 초기 임계값

- 사고 6건 재현 6/6(100%) → PRD 기준(80%) 통과. 그러나 대조군(같은 지점 2023~2025년 매일 정오)에서 10~4월 '안전'이 3%뿐이었다.
  "caution 이상 재현" 기준만으로는 사고 날을 가려낸다고 말할 수 없었다.
- 원인(위험 점수 H의 1위 요인): 파고 56%, 바람 43%. PRD 파랑 임계값(주의 1.0 m·위험 2.0 m, 너울 10·14초)이
  오리건 외해의 평상시(겨울 정오 유의파고 중앙값 2.3 m)보다 낮고, 돌풍에 풍속과 같은 구간(8·14 m/s)을 쓴 것(A가 정한 값)이 겹쳤다.

### 2차: 재조정(채택, `lib/risk/constants.ts`)

`sweep.mjs`로 후보를 비교했다. 사고에 맞추지 않고 지역 기후값과 일반 돌풍 계수로 정했다.

| 항목 | PRD 초기값 | 채택값 | 근거 |
| --- | --- | --- | --- |
| 외해 유의파고 주의·위험 | 1.0·2.0 m | 3.1·4.8 m | 겨울 정오 75%·97% 백분위 |
| 너울 주기 주의·위험 | 10·14초 | 10.5·13.2초 | 겨울 정오(파고 1 m 이상) 75%·97% 백분위 |
| 돌풍 주의·위험 | 8·14 m/s | 12·21 m/s | 풍속 구간 × 1.5(돌풍 계수) |

| | 사고 주의+ | 사고 위험 | 겨울 정오 안전·주의·위험 | 여름 정오 안전·위험 |
| --- | --- | --- | --- | --- |
| PRD 초기값 | 6/6 | 4/6 | 3% · 58% · 39% | 1% · 18% |
| 채택값 | 6/6 | 3/6 | 29% · 52% · 19% | 24% · 2% |

- 사고 시각의 '위험' 비율(50%)이 평소 겨울 정오(19%)의 약 2.6배다.
- 지점별 겨울 '안전'은 야하츠·디포베이·실레츠만 41~45%, 오터 크레스트 17~27%, 사우스 제티 끝 4%. 방파제 끝은 평소에도 위험하다는 현지 안내와 맞는다.

### 남은 약점

- 경보를 빼면 겨울 정오 '위험'이 0~16%로 떨어진다. 사고 3건의 '위험' 중 2건(디포베이·실레츠만)은 경보 강제 규칙 덕이다.
  날씨만으로 위험까지 올라가는 경우가 드물다. 경보가 없는 날의 사고를 놓칠 수 있다.
- 오터 크레스트 2018(40점)·야하츠·실레츠만(41점)은 주의 경계에 바로 걸려 있다. 임계값을 조금만 올려도 '안전'으로 떨어진다(후보 E에서 야하츠가 안전).
- 스니커 웨이브는 평균 파고보다 긴 주기 너울 묶음과 관련이 크다(오리건 주립대 연구 보도). 지금 모델은 이 특성을 직접 보지 않는다.

### 3차: 스니커 웨이브(처오름) 요인 추가 (`lib/risk/hazard.ts` `sneakerRunup`)

- 근거: 오리건 주립대 연구(2023, Natural Hazards and Earth System Sciences)는 먼 폭풍의 긴 주기 너울이 만드는 극한 처오름을 스니커 웨이브 원인으로 봤다.
  NWS 포틀랜드는 너울 약 1.5 m·12초 이상이면 스니커 웨이브 위험이 높다고 안내했다(인터뷰 보도).
- 식: 처오름 R2 = 0.043·√(H0·L0)(Stockdon 2006 소산형 해변), L0 = g·T²/2π. 여유 = 포인트·퇴로 고도 − (해수면 + R2). 조석과 같은 구간으로 점수화. 해변·갯바위·방파제만.
- 사고 6건·대조군: 거의 변화 없음(재현 6/6, 사고 위험 3/6, 겨울 정오 안전 28~29%). 사고 지점 대부분이 절벽 아래 암반이라 30 m 지형 고도가 13~30 m로 잡혀 처오름이 닿지 않는다.
- 시범 지역 포인트(뉴포트 정오 기상으로 2023~2025 겨울, 경보 제외): 해변 '위험' 30% → 42%(처오름이 1위 요인 55%), 방파제·부두·하구는 변화 거의 없음.
- **검증 안 됨**: 해변 고도(2 m 기본값)는 가정이고, 고도가 맞게 잡힌 해변 사고 사례가 없어 이 요인의 효과는 아직 확인하지 못했다. 배수(`SNEAKER.extremeFactor`)는 표준값 1.0(R2)으로 두었다(1.5·2.0도 사고·대조군 결과는 같았다).

### 팀 결정이 필요한 것

0. 해변 실제 고도(미국 USGS 3DEP 1 m 라이다)를 받아 해변 기본값 2 m를 바꿀지. 처오름 요인의 신뢰도가 여기에 달려 있다.
1. 게이트 기준에 대조군 조건을 더할지(예: 평소 겨울 정오 '안전' 25% 이상, 사고 시각 위험 비율이 평소의 2배 이상).
2. 사고 표본을 늘릴지(6건은 작다. 쿠스·클랫섭 카운티까지 넓히면 수십 건).
3. 스니커 웨이브 전용 요인(긴 주기 너울 + 해변 경사)을 더할지.
