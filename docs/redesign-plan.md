- 작성: 2026-11-24, 개발자 B(`dev-b`)
- 상태: 초안. 아래 "정해야 할 것"을 사용자가 정한 뒤 0단계부터 진행한다.

## 1. 목표

1. **지도가 실제와 똑같이 보인다.** 도로, 건물, 방파제, 절벽이 사진 질감의 3D로 보이고, 그 위에 위험 구역과 포인트가 얹힌다.
2. **화면은 지도가 주인공이다.** 기존 디자인(Material 3 기본 보라색, 내비게이션 레일 + 오른쪽 시트)은 버리고, 참고 이미지처럼 차분한 단색 팔레트, 왼쪽 패널 하나, 지도 위의 최소한의 떠 있는 정보로 다시 짠다.
3. **PRD 요구는 그대로 지킨다.** 등급은 색, 모양, 글자로 함께 구분하고, 원인 상위 3개, 수집 시각, 신뢰도, 안전 고지, 출처를 항상 보여 준다. 중급 휴대폰에서 지도 조작이 4초 안에 가능해야 한다.

## 2. 참고 이미지에서 가져올 것

첨부 이미지는 두 부분이다. 위는 Higgsfield가 3D 모델 화면을 바탕으로 만든 실사 **영상**이고, 아래는 그 바탕이 된 3D 도시 비행 앱 화면이다.

- **영상(위)은 지도로 쓸 수 없다.** Higgsfield는 이미지를 영상으로 바꾸는 생성 도구라, 사용자가 돌리고 확대하는 실시간 지도를 만들지 못한다. 앱 첫 화면 소개 영상이나 홍보물에는 쓸 수 있다.
- **"실제와 똑같은" 실시간 3D 지도**는 Google Photorealistic 3D Tiles로 만든다. 항공 촬영으로 재구성한 실제 건물·도로·지형 메시이고, 웹에서 실시간으로 돌릴 수 있다.
- **화면 구성(아래)에서 가져올 것.**
  - 왼쪽 세로 패널 하나에 큰 제목, 모드 전환, 설정, 하단 주 버튼
  - 지도 왼쪽 위에 지역명("United States / New York / Midtown Manhattan" 같은 3단 위치 표시)
  - 지도 위 가운데에 작은 상태 카드("Manual camera")
  - 하단에 재생 막대와 단계 점
  - 채도를 뺀 세이지(회녹색) 단색 팔레트, 얇은 선, 작은 글자, 넓은 여백
  - 카메라 모드: 경로 비행, 자유 비행, 걷기

## 4. 지도 기술 선택

### 4.1 실사 모드 (추천 기본)

- **렌더러: deck.gl 단독.** `Tile3DLayer`로 Google 3D Tiles를 그리고, `TerrainController`로 카메라가 지형을 따라가게 한다. deck.gl은 `CLAUDE.md` 10번의 합의된 스택에 이미 있으므로 기술 변경 합의가 필요 없다. CesiumJS로 바꾸는 것은 합의가 필요해 택하지 않는다.
- **구역과 핀.** 위험 구역은 `GeoJsonLayer` + `TerrainExtension`(`terrainDrawMode: 'drape'`)으로 실사 표면 위에 덮는다. 핀은 지면에 꽂힌 기둥 + 등급 모양 아이콘(`IconLayer`, 항상 카메라를 향함)으로 그린다.
- **Google 타일에는 지형이 들어 있다.** 그래서 실사 모드에서는 MapLibre 배경 지도, 지형 타일, 항공 사진을 쓰지 않는다. MapLibre는 2D 모드와 대체 경로에 남긴다.
- **실시간 레이어.** 바람 입자, 파고 그라데이션은 deck.gl 레이어로 옮긴다. 레이더, 구름은 넓은 범위에서만 의미가 있으므로 2D 광역 보기에서만 켠다.

### 4.2 모형 모드 (대체 경로, 참고 이미지 아래와 같은 모습)

- MapLibre의 `fill-extrusion`으로 OpenFreeMap 벡터 타일의 건물 높이를 돌출시키고, 지형 + 단색 세이지 스타일로 그린다. 키와 비용이 없다.
- 실사 타일을 못 쓰는 경우(키 없음, 한도 초과, 저사양 기기, 이 지역에 실사 데이터 없음)에 자동으로 쓴다.

### 4.3 대체 순서

실사(Google) → 모형(OSM 돌출) → 2D 지도 → 포인트 목록(WebGL 없음). 바뀔 때는 한 번만 알린다.

### 4.4 Google 타일 조건 (0단계에서 원문으로 확인)

검색 결과로만 본 내용이고 정책 원문은 아직 열어 보지 않았다.

- **출처 표시 필수.** Google 로고와 타일마다 오는 저작권 문구를 화면 아래에 모아 보여 준다. 다른 출처(Open-Meteo 등) 표시와 겹치지 않게 간격을 둔다.
- **구분 표시.** 실사 타일과 우리 데이터를 섞으면 어느 부분이 Google 데이터인지 화면에서 알 수 있어야 한다.
- **금지.** 실사 타일에서 건물 모양을 따서 우리 데이터로 만들기, 캐싱·저장·오프라인 사용.
- **비용.** PRD 조사 기준 월 1,000건 무료, 이후 1,000건당 6달러다. 최신 가격표로 다시 확인한다.
- **키 노출.** 브라우저에서 타일을 받으므로 키가 공개된다. Google Cloud 콘솔에서 HTTP 리퍼러(배포 주소)와 Map Tiles API로만 제한한다. 키는 `.env.local`의 `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`에 둔다.
- **지역 범위.** 뉴포트 해안이 실사 3D로 촬영돼 있는지 확인되지 않았다. 0단계의 첫 확인 항목이다.

### 4.5 점진 교체 (D3)

- **한 화면, 한 카메라.** 가벼운 지도와 실사를 둘 다 deck.gl 한 캔버스에 그린다. MapLibre 지도를 따로 띄워 카메라를 맞추는 것보다 단순하고, 바뀌는 순간 화면이 튀지 않는다.
- **가벼운 지도.** 공개 지형 타일(Mapzen Terrarium) 위에 USGS 항공 사진을 입힌 `TerrainLayer`다. 지금 MapLibre 3D 보기와 같은 출처다. 처음에는 이것이 구역·핀이 얹히는 지형이다.
- **실사 미리 받기.** 실사 레이어는 처음부터 그리되 투명하게(불투명도 0, 깊이 기록 끔) 둔다. deck.gl은 그려지는 레이어만 카메라를 받아 타일을 고르므로 숨기면(`visible: false`) 타일을 받지 않는다.
- **교체.** 지금 보이는 범위의 실사 타일이 다 오면(`tileset.isLoaded()`) 실사를 보이게 하고 지형 역할도 넘긴 뒤 가벼운 지도를 끈다. 한 번 바뀌면 되돌리지 않는다.
- **데이터 절약.** 브라우저가 데이터 절약(`navigator.connection.saveData`)을 알리면 실사를 받지 않는다.
- 진행 중(2026-11-24, 이 PC의 세션, 브랜치 `dev-b-photoreal`): 시험 화면에서 이 방식을 만든다. 건드리는 파일: `components/map/PhotorealView.tsx`, `PhotorealLab.tsx`, `PhotorealLabLoader.tsx`, `app/lab/`, `styles/app.css`의 시험 화면 부분. 2단계 골격 파일(`MapApp.tsx`, `MapView.tsx` 등)은 건드리지 않고, 정식 화면 연결은 2단계가 끝난 뒤에 한다.

## 5. 새 화면 구성

### 5.1 넓은 화면 (840dp 이상)

```
┌──────────────┬──────────────────────────────────────────────────────┐
│ 패널 (320)   │ 오리건주 › 뉴포트                  ┌──────────────┐ │
│              │ Yaquina Bay              [실시간 바람 7.8 · 파고 4.4]│ │
│ 브랜드       │ 야퀴나만 해안                      └──────────────┘ │
│ [지도][추천] │                                                      │
│ [설정]       │                                                      │
│ ──────────   │                실사 3D 지도                           │
│ 포인트 상세  │          (구역이 표면에 덮이고, 핀이 서 있음)         │
│  또는        │                                                      │
│ 추천 5곳     │                                                      │
│              │                         [개요 | 투어 | 자유] [2D/3D] │
│ ──────────   │ ┌──────────────────────────────────────────────────┐ │
│ [더 안전한   │ │ ▶  지금 ●──────────────── +72시간   오늘 01:00    │ │
│  곳 찾기]    │ │    ████▓▓▓░░░░▓▓████ (시간대별 위험 띠)           │ │
│              │ └──────────────────────────────────────────────────┘ │
│              │ Google · Weather data by Open-Meteo.com · OSM        │
└──────────────┴──────────────────────────────────────────────────────┘
```

- **왼쪽 패널 하나.** 기존의 내비게이션 레일과 오른쪽 시트를 합친다. 위는 탭(지도·추천·설정), 가운데는 내용(선택 없음: 추천 5곳, 선택됨: 포인트 상세), 아래는 주 버튼.
- **지도 왼쪽 위 지역명.** 3단 위치 표시(주 › 도시 / 큰 지역명 / 세부 구간). 검색은 지역명을 누르면 펼쳐진다.
- **가운데 위 상태 카드.** 실시간 바람·파고, 경보 발효 여부, 데이터 지연을 한 장에 보여 준다. 공식 경보가 있으면 이 카드가 위험 색으로 바뀐다.
- **하단 시간 막대.** 재생 버튼, 72시간 슬라이더, 선택 시각. 슬라이더 아래에 선택한 포인트(없으면 전체 최고 위험)의 시간대별 위험 띠를 깔아 "언제 위험한지"를 지도 화면에서 바로 읽게 한다.
- **카메라 모드.** 참고 이미지의 비행 모드를 낚시에 맞게 바꾼다.
  - 개요: 시범 구간 전체를 비스듬히 내려다본다(기본)
  - 투어: 추천 포인트를 차례로 날아가며 보여 준다(참고 이미지의 경로 비행)
  - 자유: 마우스·키보드로 자유롭게 움직인다
- **오른쪽 아래.** 2D/3D 전환, 레이어, 내 위치.

### 5.2 중간 화면 (600~839dp)

왼쪽 패널이 접혀 아이콘 줄이 되고, 포인트를 고르면 패널이 지도 위로 겹쳐 펼쳐진다.

### 5.3 좁은 화면 (600dp 미만)

- 패널은 아래에서 올라오는 시트(접힘: 등급 한 줄, 중간: 원인 상위 3, 펼침: 전체)로 바뀐다.
- 지역명과 상태 카드는 위에 한 줄로 줄인다.
- 시간 막대는 시트 바로 위에 붙는다.
- 탭(지도·추천·설정)은 시트 머리에 둔다. 하단 내비게이션 바는 없앤다.

### 5.4 포인트 상세 (패널 안)

순서는 "10초 안에 이해"에 맞춘다.

1. 포인트명, 유형, 접근(주차장에서 도보 n분)
2. 등급 카드: 모양 아이콘 + 등급 글자 + 점수 + 시각 + 신뢰도
3. 원인 상위 3개(문장)
4. 시간대별 위험 띠(누르면 그 시각으로 이동)
5. 지형 요약, 수집 시각, 안전 고지
6. 주 버튼: 위험이면 "더 안전한 곳 찾기", 아니면 "이 포인트로 카메라 이동"

## 6. 디자인 시스템

- **Material 3 구조는 유지하고 색을 새로 만든다.** `CLAUDE.md` 10번이 Material 3를 기준으로 정했으므로, 역할 이름(`--md-primary`, `--md-surface-container` 등)과 토큰 파일 구조는 두고 값만 세이지 계열 사용자 지정 테마로 바꾼다. 기술 변경이 아니라 테마 변경이다.
- **팔레트(초안).** 참고 이미지 기준 기본 색은 회녹색(#5f7a68 근처), 배경은 어두운 올리브 회색(#1c211e 근처)이다. 1단계에서 대비 4.5:1 이상을 확인하며 확정한다.
- **등급 색.** 세이지 배경 위에서도 섞이지 않도록 채도를 유지한다. 지도 위 등급 색은 실사 사진 위에서 다시 대비를 잰다. 안전 원, 주의 삼각형, 위험 팔각형 모양과 글자는 그대로 둔다.
- **글자.** 한글은 Pretendard, 숫자는 고정폭 숫자(tabular). 큰 지역명은 가벼운 굵기로 크게 쓴다.
- **표면.** 반투명 패널(배경 흐림)은 지도 위 떠 있는 카드에만 쓴다. 휴대폰 성능이 떨어지면 불투명으로 바꾼다.
- **움직임.** 카메라 이동은 1~2초 감속 곡선으로 한다. `prefers-reduced-motion`이면 즉시 이동한다.

## 7. 단계별 계획

### 0단계. 확인용 시제품 (1~2일, 화면에 내보내지 않음)

1. 사용자가 Google Cloud에서 Map Tiles API 키를 만든다(D2).
2. 의존성 추가: `@deck.gl/core`, `@deck.gl/layers`, `@deck.gl/geo-layers`, `@deck.gl/extensions`, `@deck.gl/react`. `CLAUDE.md` 5번대로 `pull` 먼저, 이 변경만 따로 커밋하고 `ship` 한다.
3. 숨은 시험 페이지(`/lab/photoreal`)에서 확인한다.
   - 뉴포트 해안에 실사 3D가 있는가, 방파제와 부두가 알아볼 만한가
   - 구역을 표면에 덮었을 때 보기 좋은가
   - 휴대폰 조건(375×812, Fast 4G, CPU 4배 감속)에서 조작 가능까지의 시간, 끊김
   - 한 번 방문에 쓰는 타일 요청 수(비용 추정)
   - 정책 원문 확인(4.4)
4. 결과로 D1, D3를 확정한다. 실사가 없거나 너무 느리면 모형 모드를 기본으로 한다.

- 완료 기준: 위 확인 결과가 이 문서의 "확인 기록"에 적혀 있다.

### 1단계. 디자인 시스템 교체

1. `styles/tokens.css`를 세이지 테마(밝음·어두움)로 바꾼다.
2. Pretendard 글꼴, 글자 단계, 모서리, 그림자, 반투명 표면 토큰을 정한다.
3. 기본 부품을 새 모습으로 만든다: 버튼, 탭, 칩, 세그먼트, 슬라이더, 카드, 등급 배지.

- 완료 기준: 설정 화면(지도 없음)이 새 디자인으로 보이고 대비 검사를 통과한다.

### 2단계. 새 화면 골격

1. `AppShell`을 왼쪽 패널 구조로 바꾸고 내비게이션 레일, 하단 바, 오른쪽 시트를 없앤다.
2. 지역명, 상태 카드, 시간 막대(위험 띠 포함), 오른쪽 아래 컨트롤을 새로 배치한다.
3. 포인트 상세와 추천 목록을 패널 안으로 옮긴다.
4. 세 화면 폭(600 미만, 600~839, 840 이상)을 모두 맞춘다.
5. 지도 자리에는 지금의 MapLibre 지도를 그대로 둔다. 지도 교체와 화면 교체를 나눠야 문제가 생겼을 때 원인을 찾기 쉽다.

- 완료 기준: 새 화면에서 기존 기능(검색, 필터, 시간 슬라이더, 상세, 추천, 여섯 가지 상태)이 모두 동작한다. 이때 `ship` 한다.

### 3단계. 실사 3D 지도

1. `components/map/PhotorealView.tsx`(deck.gl)를 만든다: 3D Tiles, 표면에 덮은 구역, 핀, 카메라.
2. 모형 모드(`MapView`에 건물 돌출과 세이지 스타일 추가)를 만든다.
3. 대체 순서(4.3)와 자동 전환을 넣는다.
4. Google 로고와 출처 표시를 넣는다.
5. 바람·파고 레이어를 실사 모드로 옮긴다.

- 완료 기준: 실사 모드에서 핀 선택, 시간 이동, 구역 색 변경이 동작하고, 키가 없으면 모형 모드로 자연스럽게 넘어간다.

### 4단계. 카메라 모드와 마무리

1. 개요, 투어, 자유 카메라 모드
2. 키보드로 핀 이동, 스크린 리더 문구, 터치 대상 48dp
3. 첫 진입 시 시범 구간으로 날아 들어오는 연출(움직임 줄이기 설정 존중)
4. (선택) Higgsfield로 만든 소개 영상을 첫 화면 배경에 쓴다. 지도를 불러오는 동안만 보여 준다.

### 5단계. 검증

- `npm run lint`, `npm run typecheck`, `npm run build`
- 넓은 화면과 휴대폰 크기에서 직접 열어 확인
- 휴대폰 조건 성능 측정을 다시 하고 `docs/roles/developer-b-map-ui.md`의 검증 기록을 갱신
- 접근성 자동 점검(지도·추천·설정 화면)
- 개발자 C에게 실제 기기 테스트를 요청

## 10. 확인 기록

### 2026-11-24, 0단계 시험 화면(`/lab/photoreal`)

배포용 빌드(`npm run build` 후 `next start`)로 쟀다. 포인트·구역은 예시 데이터(임시 원, 반지름 170 m)다.

| 항목 | 결과 |
| --- | --- |
| 뉴포트 해안 실사 3D | **있다.** 남·북 방파제의 바위, 야퀴나만 다리, 마리나, 시내 건물, 부서지는 파도, 지나가는 배의 물결까지 보인다 |
| 구역을 표면에 덮기 | 동작한다. 실사 표면 위에 반투명으로 깔린다 |
| 핀 | 지형 높이에 맞춰 선다. 건물에 가려지지 않는다 |
| 출처 | 타일마다 오는 저작권 문구(Google; Data SIO, NOAA, U.S. Navy, NGA, GEBCO; IBCAO; Airbus)를 모아 표시한다 |
| 넓은 화면, 제한 없음(1440×900) | 루트 타일셋 0.6초, 첫 타일 0.7초 |
| 휴대폰 조건(375×812, Fast 4G, CPU 4배 감속) | 루트 요청 시작 4.4초, 루트 타일셋 8.1초, **첫 타일 8.7초** (기준 4초 초과). 43초 동안 타일 231건, 6.7 MB를 받고도 계속 받는다 |
| 첫 화면 자바스크립트 | 533 KB, 그중 deck.gl 묶음이 290 KB |
| 비용 단위 | 페이지를 열 때마다 루트 요청 1건. 무료 1,000건이면 한 달 방문 약 1,000회 |

**판단.**

- D1(실사 기본)은 유지한다. 시범 지역의 실사 품질이 충분하다.
- D3(휴대폰): 휴대폰 조건에서 첫 타일까지 8.7초라 4초 기준을 못 맞춘다. 그래서 **먼저 가벼운 지도(MapLibre, 기존 측정 2.8초)를 띄워 바로 조작하게 하고, 실사 타일이 준비되면 실사로 바꾸는 방식**을 제안한다. 데이터를 아끼는 설정(저사양·절약 모드)이면 실사를 켜지 않는다.
- 남은 확인: 실제 휴대폰에서 끊김, Google 정책 원문(4.4), 최신 가격표.

### 2026-11-24, 점진 교체(4.5) 시험

같은 휴대폰 조건(375×812, Fast 4G, CPU 4배 감속), 배포용 빌드, 매번 새 브라우저 컨텍스트(캐시 없음).

| 측정 | 결과 |
| --- | --- |
| 가벼운 지도(deck.gl `TerrainLayer`)만, `?mode=light` | 첫 화면 **4.8초**. 타일은 3.9초에 왔고, 나머지는 자바스크립트 시작(요청 시작 2.8초)과 지형 메시 만들기 |
| 점진 교체, 1회 | 첫 실사 타일 4.3초, 가벼운 지도 5.7초(실사와 대역폭을 나눠 씀), **실사로 교체 39.2초**(보이는 범위를 다 받을 때까지 기다림) |
| 점진 교체, 2회 | 첫 실사 타일 **4.1초**, 가벼운 지도 4.6초 |
| 참고: 지금 MapLibre 지도 | 지도 첫 표시(`load`) 2.8초(이전 측정) |

**판단.**

- 0단계의 8.7초는 첫 요청이 차가웠던 한 번의 값이었다. 다시 재면 첫 실사 타일은 약 4초다.
- deck.gl 안의 가벼운 지도는 실사 첫 타일보다 느리다. 가벼운 지도를 먼저 보여 줘도 빨라지지 않고, 교체 기준(보이는 범위를 다 받음) 때문에 실사가 30초 넘게 늦게 보인다. **이 방식은 쓰지 않는 것이 낫다.**
- 선택지(사용자가 정한다):
  1. **실사를 바로 보여 준다.** 실사는 거친 타일부터 받아 점점 선명해지므로 따로 교체할 필요가 없다. 데이터 절약, 키 없음, 실사 오류일 때만 가벼운 지도로 대신한다. 4초 기준에 걸쳐 있으므로 자바스크립트 시작을 당기는 작업(Google 주소 미리 연결, 묶음 나누기)을 함께 한다.
  2. **지금 MapLibre 지도(2.8초)를 먼저 띄우고 실사가 준비되면 바꾼다.** 기준은 확실히 맞추지만 지도 엔진 두 개를 한 화면에서 맞춰야 하고, 2단계 세션이 고치는 `MapView.tsx`·`MapApp.tsx`를 건드려야 하므로 2단계가 끝난 뒤에만 할 수 있다.

**시험 중 고친 것.**

- 개발 모드에서 효과가 두 번 실행될 때 Deck이 만든 첫 캔버스가 남아 지도를 300px 밀어내던 문제. 캔버스를 컴포넌트가 직접 그리게 했다.
- `TerrainController`가 지형 높이를 읽을 때 "Picked non-existent layer" 오류가 나던 문제. 실사 타일 레이어에 `pickable: '3d'`를 줬다.
