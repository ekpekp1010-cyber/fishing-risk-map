# 개발자 A 역할 계획: 데이터·위험도 엔진

- 브랜치: `dev-a`
- 한 줄 요약: 위성·지형 데이터와 예보를 모아 "이 포인트는 이 시각에 몇 점이고 왜 위험한가"를 계산해 API로 내준다.
- 상대: 개발자 B는 이 API와 타일을 받아 3D 지도와 화면을 만든다(`docs/roles/developer-b-map-ui.md`).

## 요구사항 재정리

PRD의 MVP 기능 네 개 중 A가 책임지는 부분이다.

| PRD 기능 | A의 책임 |
| --- | --- |
| F1. 위성·지형 기반 환경 분석 | 전부. 포인트 목록, 지형 지표, 지형 취약성 점수 V, 위험 구역 도형 |
| F2. 포인트별 위험도 표시 | 계산 전부. 예보 수집, 시간대 위험요인 H(t), 최종 점수 R(t), 원인 상위 3개 문장 |
| F3. 3D 낚시 지도 | 재료 공급. 지형 타일, 구역 타일, 시간별 구역 등급 API |
| F4. 안전 낚시 장소 추천 | 계산 전부. 추천 정렬과 추천 이유 문장 |

시범 지역은 미국 오리건주 뉴포트, 야퀴나 헤드에서 사우스 비치까지 남북 약 9 km 해안이다.
작업 범위(대략): 북위 44.59°~44.69°, 서경 124.10°~124.02°.

## 소유 경로

| 경로 | 내용 |
| --- | --- |
| `pipeline/` | 파이썬 배치: 데이터 내려받기, 지표 계산, 점수, 타일 제작 |
| `supabase/` | 스키마, 마이그레이션, 시드 |
| `app/api/` | Route Handlers |
| `lib/risk/` | 점수 계산 순수 함수(H, R, 등급, 원인 문장) |
| `lib/server/` | Supabase 접근, Open-Meteo·NOAA·NWS 클라이언트 |
| `lib/contract/` | 공유 타입과 예시 응답 |

그 밖의 경로는 읽기만 한다. 특히 `app/`의 화면, `components/`, `lib/map/`은 B의 것이다.

## 단계별 계획

### 0단계. 기반과 계약 (B를 막지 않기 위해 가장 먼저)

1. `lib/contract/types.ts`에 `docs/api-contract.md`의 타입을 그대로 옮긴다.
2. `lib/contract/fixtures/`에 예시 응답 4개를 만든다. 세 등급, `stale: true`, 경보 있음, 빈 목록을 모두 포함한다.
3. Supabase 프로젝트를 만들고 PostGIS를 켠다. 테이블 초안:
   `spots`, `terrain_scores`, `zones`, `forecast_cells`, `forecast_hourly`, `alerts`.
4. `.env.example`에 필요한 환경 변수 이름을 적는다(값은 적지 않는다).

- 완료 기준: B가 fixtures만으로 화면 개발을 시작할 수 있다. `ship` 완료.
- 주의: Next.js 프로젝트 생성은 B가 먼저 한다. B의 첫 `ship` 전에는 `pipeline/`, `supabase/`, `docs/`에서만 작업하고, 그 뒤에 `lib/contract/`를 추가한다.

### 1단계. 환경 분석 (F1)

1. **포인트 목록.** OpenStreetMap에서 방파제, 부두, 해변, 암반 해안, 주차장, 도로를 뽑아 후보를 만들고 사람이 검수한다. 목표 30곳 이상.
   야퀴나 헤드는 낚시 허용 여부가 확인되지 않았으므로 확인 전에는 포인트에서 뺀다.
2. **데이터 내려받기.** 작업 범위만 잘라 받는다.
   Copernicus DEM GLO-30, JRC Global Surface Water(출현 빈도·계절성), ESA WorldCover, Sentinel-2 L2A(최근 구름 적은 장면), GEBCO.
3. **지표 계산.** 포인트 반경 500 m, 30 m 격자: 경사, 평균해면 대비 고도, 수변 경계까지 거리, 지표 피복, 물 출현 빈도, 파랑 노출 방향, 퇴로(도로·주차장까지 거리와 고도차).
4. **지형 취약성 V.** PRD의 가중치(경사 20, 저지대 20, 침수 흔적 15, 수변 근접 10, 파랑 노출 15, 지표 상태 10, 퇴로 10)로 0~100점을 만들고 요인별 기여도를 함께 저장한다.
5. **위험 구역 도형.** 해안선을 따라 구역 폴리곤을 만들고 `zoneId`를 붙인다. `tippecanoe`로 PMTiles를 만들어 Supabase Storage에 올린다.
6. **지형 타일.** DEM을 terrain-RGB 타일로 만들어 올리고 주소를 B에게 알린다.

- 완료 기준(게이트 1): 포인트 30곳 이상에 V와 사용 데이터의 제작 연도가 저장된다. 표본 10곳의 점수가 위성 사진·현장 사진으로 본 인상과 어긋나지 않는다.
- 검증: `pytest pipeline/tests` (경사·거리 계산의 단위 테스트, 점수 범위 0~100).

### 2단계. 위험도 계산 (F2)

1. **예보 수집기.** 0.05° 격자 셀 단위로 Open-Meteo Forecast, Marine, Flood를 1시간마다 불러 `forecast_hourly`에 저장한다. 수집 시각을 함께 저장한다. Vercel Cron으로 실행한다.
2. **조석과 수위.** Open-Meteo 해수면 높이를 쓰고, NOAA 관측소 South Beach(9435380)의 실측 수위로 차이를 보정한다.
3. **경보.** NWS API에서 해당 지역의 발효 중 경보를 가져온다. 경보가 있거나 뇌우가 예보되면 등급을 `danger`로 고정한다.
4. **H(t)와 R(t).** `lib/risk/`에 순수 함수로 구현한다. `R = min(100, 0.4·V + 0.6·H + B)`. 임계값은 PRD 표의 초기값을 상수 파일 하나에 모은다.
5. **원인 문장.** 기여도가 큰 순서로 최대 3개를 한국어 문장으로 만든다. 예: "너울 주기 13초, 파고 2.1 m".
6. **API.** `GET /api/spots`, `GET /api/spots/{id}/risk`를 계약대로 구현한다.

- 완료 기준(게이트 2): 어떤 포인트·시각을 골라도 등급, 원인, 수집 시각이 나온다. 링컨 카운티 일대의 과거 사고 사례(지점과 시각)를 재계산했을 때 80% 이상이 `caution` 또는 `danger`로 나온다.
- 검증: `lib/risk/`의 단위 테스트(경계값 39/40, 69/70, 경보 강제 규칙, 원인 정렬). 실제 응답이 fixtures와 같은 모양인지 타입으로 확인.

### 3단계. 지도 지원 (F3)

1. `GET /api/zones/grades`를 구현한다. 구역 등급은 구역에 속한 포인트 또는 구역 중심의 점수로 계산한다.
2. API 응답에 캐시 헤더를 붙인다(정시 단위로 바뀌므로 다음 정시까지).
3. B가 요청한 필드를 계약에 반영한다.

- 완료 기준(게이트 3 기여): 시간 슬라이더를 움직였을 때 구역 등급 응답이 1초 안에 온다.

### 4단계. 추천 (F4)

1. `GET /api/recommendations`를 구현한다. 반경 안에서 `danger`를 빼고 `점수`와 `도보 시간`을 합쳐 정렬한다.
2. 추천 이유 문장을 만든다. 예: "파랑이 가려지는 만 안쪽, 주차장에서 3분".

- 완료 기준(게이트 4 기여): 추천된 모든 포인트가 같은 시각 기준 현재 포인트보다 점수가 낮다.

## 위험 요소

| 위험 | 수준 | 대응 |
| --- | --- | --- |
| 30 m DEM으로 갯바위 단위 높낮이를 못 봄 | 높음 | 신뢰도를 `low`로 표시, 위험한 쪽으로 판정, 미국 1 m급 라이다 지형 제공 여부 확인 |

## 진행 기록 (2026-11-24)

PRD(`docs/prd.md`)에 수치가 없어 정한 값이다. 모두 `lib/risk/constants.ts`에 모여 있고 게이트 2 보정 때 고친다.

- 요인 점수는 PRD의 '주의 시작'을 40점, '위험 시작'을 70점에 맞춘 구간 선형 보간이다. 0점·100점 지점은 정한 값이다.
- H(t) 가중치는 PRD에 없어 합 1로 정했다. 합이 1이면 가중합이 최댓값을 넘지 못하므로 H(t)는 사실상 가장 큰 요인 점수다.
- 돌풍에도 풍속과 같은 구간(8·14 m/s)을 쓴다(위험한 쪽).
- B(t): 저지대(3 m 이하)+조석 주의 이상 10점, 급경사(20° 이상) 방파제·암반+너울 주의 이상 10점, 야간+다른 요인 주의 이상 5점. 최대 20점.
- 신뢰도 낮음(조석 위험, 저지대 가산, 핵심 예보 누락)이면 등급 경계 5점 아래 점수를 경계로 올린다.
- 경보·뇌우로 `danger`를 강제할 때 점수는 바꾸지 않는다(계약 fixtures와 같음).
